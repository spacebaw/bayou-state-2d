# Bayou State 2D

*Build the campus. Beat the swamp. Fill the stadium.*

A handcrafted **HD 2D Isometric HTML5 Canvas** edition of **Bayou State** — sharing the exact decoupled TypeScript simulation core, hydrology CA, 50+ LSU-inspired colleges & venues, football set pieces, hurricane surge, Mardi Gras parades, College Town, and procedural WebAudio from [Bayou State 3D](https://github.com/spacebaw/bayou-state-3d), rendered in a warm miniature-diorama 2D art style with zero external runtime dependencies.

**Play Live:** https://spacebaw.github.io/bayou-state-2d/

## Controls
- **Pan:** `W A S D` / Arrow keys / Left-drag (inspect mode) or Right-drag
- **Zoom:** Scroll wheel (`0.45×` to `2.4×`) · `Home` resets camera
- **Quick Keys:** `F` Flood Risk · `P` Pilings toggle · `R` Rotate · `X` Bulldoze · `C` Postcard Photo Mode · `Space` Pause · `1/2/4` Speed
